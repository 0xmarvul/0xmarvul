**Vulnerability classes I specialize in:**

- Broken Access Control (IDOR, BAC, privilege escalation)
- Authentication bypass and session management flaws
- Information disclosure (JS source maps, exposed configs, API key leakage)
- API security (unauth endpoints, mass assignment, BOLA)
- Injection (SQLi, SSTI, SSRF)
- Cross-site scripting (reflected, stored, DOM-based)
